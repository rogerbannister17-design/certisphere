# Iconography

## Style

Certisphere icons use simple line-based forms with consistent stroke widths and minimal colour.

## Rules

- Use primary and accent blues only unless semantic state requires another colour.
- Use white icons on dark navy surfaces.
- Use outline icons for default states.
- Use filled icons only for selected, active, or high-emphasis states.
- Use consistent stroke widths, typically 2 px at 24 px icon size.
- Use rounded caps and corners where supported.
- Size icons in 4 px increments: 16, 20, 24, 32, 40.
- Pair unfamiliar icons with labels or accessible names.

## Approved Concepts

- Shield: security, assurance, control.
- Globe: integrated systems, certification network.
- Nodes: relationships, knowledge graph, collaboration.
- Checkmark: approval, completion, verification.
- Document: controlled information.
- Chart: improvement, performance, management review.
- Lock: restricted access.

## Asset Location

Icon assets are governed under `docs/brand/assets/icons/`.
