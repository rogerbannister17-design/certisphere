## Who Should Use This Portal

Use this portal if you are creating, reviewing, approving, or implementing:

- Product UI.
- Website pages.
- Sales collateral.
- Investor material.
- Customer presentations.
- Training material.
- Reports and exported documents.
- Audit packs or certification-facing documents.
- Videos and motion assets.
- AI-generated brand content.
- Logo, icon, illustration, or design token updates.

## Approval Path

Use this path for governed assets:

1. Select the correct guidance from this portal.
2. Use approved assets and token values.
3. Complete a self-review against the relevant guidance.
4. Complete [Brand Review Checklist](BRAND_REVIEW_CHECKLIST.md) for customer-facing, certification-facing, investor-facing, or implementation-impacting assets.
5. Record the approval decision in the pull request, review record, or governed asset log.
6. Store approved assets in the correct asset folder.

## Product Implementation Rule

Brand documentation governs intent and usage. Product implementation must use the approved design-system and central brand configuration in the application codebase. Do not copy values from examples into isolated implementation files when a governed shared configuration exists.

## AI Usage Rule

AI may support drafting, review, exploration, and visual briefing. AI output requires human review before it becomes controlled information, product copy, marketing copy, customer-facing content, or implementation-ready design direction.

## Escalation

Escalate for product owner review when an asset:

- Changes core positioning.
- Introduces a new visual style.
- Adds or changes certification, compliance, AI, security, or customer outcome claims.
- Changes design tokens.
- Uses customer names, logos, screenshots, or data.
- Is intended for certification-facing or investor-facing use.
