# Document Templates

## Purpose

Certisphere documents must look consistent across governance records, reports, proposals, product specifications, release documentation, customer onboarding, audit outputs, and exported controlled information.

## Template Rules

- Use the approved logo.
- Use Aptos or the approved fallback.
- Use Midnight Navy for main headings.
- Use Azure Blue for links and controlled emphasis.
- Use tables with clear headers and sufficient spacing.
- Include document title, owner, version, status, date, and classification where relevant.
- Use footer text consistently for copyright and confidentiality.
