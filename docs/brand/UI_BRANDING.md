# UI Branding

## Product Experience

Certisphere product UI should feel quiet, precise, professional, and designed for repeated operational use.

## UI Rules

- Use dense but organised layouts for operational tools.
- Prioritise table, form, workflow, dashboard, and review ergonomics over marketing composition.
- Use cards only for repeated items, modals, or genuinely framed tool surfaces.
- Use restrained colour with Azure Blue for key actions and state.
- Use icons with labels where meaning could be ambiguous.
- Maintain visible focus states.
- Preserve WCAG 2.2 AA accessibility.
- Do not use decorative gradients or effects in core operational workflows.

## Components

Buttons, inputs, toggles, navigation, alerts, tables, modals, and cards must follow the interaction and colour rules in the preserved [Brand Design System Source](BRAND_DESIGN_SYSTEM_SOURCE.md).

## Product Branding

Application titles, metadata, login screens, loading states, dashboard headers, reports, and exports must use the central Certisphere brand configuration defined in the product codebase.
