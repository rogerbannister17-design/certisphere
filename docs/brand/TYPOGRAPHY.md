# Typography

## Primary Typeface

Aptos is the default typeface for product UI, digital documentation, presentations, and commercial material.

## Fallback Typefaces

- Segoe UI for Windows environments.
- Avenir for professionally typeset PDF and print material where licensed and available.
- System sans-serif fallback only where platform constraints require it.

## Type Scale

| Level | Weight | Size | Line Height | Use |
| --- | --- | --- | --- | --- |
| H1 | Semibold | 56 px | 1.1 | Cover titles and hero headlines. |
| H2 | Semibold | 40 px | 1.1 | Section titles. |
| H3 | Semibold | 32 px | 1.2 | Subsection headings. |
| H4 | Semibold | 24 px | 1.3 | Page subtitles and callouts. |
| Body | Regular | 16 px | 1.5 | Main content. |
| Small | Regular | 14 px | 1.4 | Captions, metadata, and compact table labels. |

## Rules

- Use left-aligned paragraphs for readability.
- Keep body text at 16 px or larger in digital experiences.
- Avoid negative letter spacing.
- Keep line lengths comfortable for reading.
- Use underlines only for links.
- Use bold or semibold for emphasis rather than introducing extra colours.
